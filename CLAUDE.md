# Правила работы Claude в этом репозитории

## Агенты: подбор под каждую задачу

Владелец репозитория разрешил и просит: для каждой задачи подбирать агентов из `.claude/agents/`
(набор The Agency, msitarzewski/agency-agents) и поручать работу им.

1. **Разбить задачу на подзадачи** и для каждой выбрать самого подходящего агента по его описанию
   (например: план урока → Corporate Training Designer, вёрстка → UI Designer / Frontend Developer,
   тексты и истории → Narratologist / Content Creator, проверка кода → Code Reviewer,
   финальная проверка → Reality Checker).
2. **Перед запуском коротко сообщить пользователю план**: какие подзадачи, какой агент, что
   выполняется параллельно, а что последовательно.
3. Без агентов (сам) — только мелочи: ответ на вопрос, правка в одну-две строки, git-операции.

## Параллельный режим без конфликтов

- **Независимые подзадачи запускать параллельно**: несколько вызовов Agent в одном сообщении,
  в фоне (`run_in_background`).
- **Зависимые подзадачи — последовательно**: следующий агент стартует, когда готов результат
  предыдущего.
- **Владение файлами**: в промпте каждого агента явно перечислить файлы, которые ему разрешено
  менять, и запретить трогать остальные. Два параллельных агента никогда не получают один и тот
  же файл.
- **Если пересечения по файлам не избежать** — запускать таких агентов с `isolation: "worktree"`
  (каждый в своей копии репозитория), а потом основная сессия сама сливает изменения.
- **Агенты только для чтения** (ревью, исследование, анализ) могут работать параллельно с кем угодно.
- **Агенты не коммитят и не пушат.** Основная сессия собирает результаты, проверяет итог
  (открывает страницы, сверяет данные), разрешает конфликты, затем коммитит и пушит.
- После параллельного этапа — при необходимости один агент-проверяющий (Code Reviewer или
  Reality Checker) по итоговому результату.

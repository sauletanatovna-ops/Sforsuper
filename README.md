# English Word Bank

Словарь для повышения уровня английского:

- **[AWL.md](AWL.md)** — Academic Word List (Coxhead, 2000): 570 самых частых слов академических текстов в 10 подсписках, с переводом на русский.
- **[PHRASAL_VERBS.md](PHRASAL_VERBS.md)** — 190 частотных фразовых глаголов с переводом и примерами; 56 из них отмечены как полезные для академического письма.
- **[index.html](index.html)** — тренажёр: список с поиском, карточки (EN → RU и RU → EN), тест с 4 вариантами ответа, озвучка и отметки «знаю» (сохраняются в браузере). Откройте файл в браузере, рядом должен лежать `data.js`.

Все слова хранятся в `data.js`. После правок пересоберите markdown-словари:

```
node tools/build-md.js
```
